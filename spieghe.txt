3. Chiamata HTTP grezza (curl/fetch), ma con più attenzione
Tecnicamente puoi anche mandare richieste JSON-RPC dirette via curl, ma è scomodo: devi gestire tu l'handshake MCP (initialize, poi tools/list, poi tools/call), gli header giusti (Content-Type: application/json, Accept: application/json, text/event-stream), e il body in formato JSON-RPC 2.0. L'SDK (opzione 1) fa tutto questo per te — per questo è la via consigliata anche solo per "provare" il server senza un client AI vero.

4. Claude Desktop (o un altro client MCP "vero") — il modo pensato per l'uso reale: non testi il server, lo usi dentro una conversazione con un assistente AI

La differenza chiave del quarto modo rispetto ai primi tre: con Inspector/script/curl tu decidi quale tool chiamare e con quali parametri. 
Con Claude Desktop è il modello a decidere, leggendo la tua domanda in linguaggio naturale ("che tempo fa in Maine?") e capendo da solo che deve chiamare get-forecast con latitude: 44.61, longitude: -67.51.

Come stanno davvero le cose ora (2026):
claude_desktop_config.json accetta solo server stdio (comando + argomenti locali, come la tua vecchia configurazione con "command": "node"). 
Il campo "url" che ti ho fatto scrivere è pensato per Claude Code (un altro prodotto), non per Claude Desktop — Claude Desktop lo ignora o lo scarta.
La via corretta per server remoti in Claude Desktop: Connettori personalizzati (UI), non il file JSON

In dettaglio:
Apri Claude Desktop
Vai su Settings → Connectors (potrebbe chiamarsi "Integrations" a seconda della versione)
Cerca un'opzione tipo "Add custom connector"
Inserisci l'URL del tuo server:

   https://weather-five-eosin-13.vercel.app/mcp

Salva — non serve editare file, non serve riavviare manualmente il processo come con la config JSON

Ripristina la vecchia config JSON
Nel frattempo, rimetti la configurazione stdio originale che avevi (quella con "command": "node") se stai ancora usando quel server locale per altro — altrimenti lasciala vuota se usi solo il connettore remoto via UI.
Vuoi che ti dia una mano a verificare esattamente dove si trova quella voce di menu, dato che le versioni di Claude Desktop possono differire leggermente? Fammi sapere cosa vedi in Settings e ti guido passo passo.

Un dettaglio tecnico importante da sapere: con questo metodo, Claude si collega al tuo server dall'infrastruttura cloud di Anthropic, non dal tuo PC. Se fosse stato localhost, non avrebbe funzionato con questo metodo (serve tunneling tipo ngrok).
